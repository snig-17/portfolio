## 🎨 Customization Guide

### Color Scheme Modification
Update CSS custom properties in `css/style-enhanced.css`:
```css
:root {
    --bg-primary: #0a0a0a;          /* Deep black background */
    --accent-primary: #ff6b35;       /* Warm orange accent */
    --accent-secondary: #ffa726;     /* Warm amber secondary */
    --text-primary: #ffffff;         /* Pure white text */
    --text-secondary: #b4b4b4;       /* Subtle gray text */
}
```

### Typography Customization
Change font imports in the HTML head:
```html
<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@300;400;500;600;700&family=Syne:wght@400;500;600;700;800&display=swap" rel="stylesheet">
```

### Animation Preferences
Modify transition timing in CSS:
```css
:root {
    --transition-fast: 0.2s cubic-bezier(0.25, 0.46, 0.45, 0.94);
    --transition-medium: 0.4s cubic-bezier(0.25, 0.46, 0.45, 0.94);
    --transition-slow: 0.8s cubic-bezier(0.25, 0.46, 0.45, 0.94);
}
```
