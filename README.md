
# Portfolio Website

A modern portfolio website featuring glass morphism design and personal photography backgrounds.

## 🚀 Live Demo

**URL**: [https://snig-17.github.io/portfolio](https://snig-17.github.io/portfolio)

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Glass morphism effects, CSS Grid, Flexbox
- **JavaScript** - Intersection Observer API, DOM manipulation
- **GitHub Pages** - Static hosting

## 🎨 Features

### Design
- Glass morphism UI with backdrop-filter blur effects
- iOS-inspired color gradients (#007AFF, #5856D6, #AF52DE, #FF2D92, #FF6B35)
- Personal photography backgrounds (aerial, coastal, mountain, countryside)
- Responsive design with mobile-first approach

### Sections
- **Hero** - Animated greeting with aerial photography
- **About** - Personal introduction with mountain landscape
- **Experience** - Interactive timeline with coastal village background
- **Projects** - GitHub repositories in glass card grid
- **Social** - Contact links with countryside photography

### Interactive Elements
- Scroll-based animations using Intersection Observer
- Interactive timeline with hover effects
- Glass card hover animations
- Smooth scrolling navigation

## 🔧 Development

### Local Development
```bash
# Clone repository
git clone https://github.com/snig-17/portfolio.git
cd portfolio

# Serve locally
python3 -m http.server 3000
# or
npx serve .
```

### Deployment
- Hosted on GitHub Pages
- Auto-deploys from `genspark_ai_developer` branch
- Custom domain support available
